# Research & Technical Decisions: Google Search Console Indexing & SEO Fix

## 1. Canonical URL Strategy

### Decision
Standardize canonical URL generation in `src/components/Global/Meta.astro` to ensure every page renders a self-referencing canonical URL corresponding to its primary indexable path.

### Rationale
- Previously, `Meta.astro` stripped `/en/` from URLs like `/en/videos/` and set canonical to `/videos/`, while both `/en/videos/` and `/videos/` were generated by Astro. Googlebot crawled `/en/videos/`, saw canonical `/videos/`, and flagged 7 pages as "Alternate page with proper canonical tag".
- By ensuring every canonical page has one clear, primary URL format and avoiding duplicate routes in sitemaps, we resolve Google Search Console's indexing warnings.

### Alternatives Considered
- *Keep duplicate `/en/videos/` and `/videos/` with cross-canonical tags*: Disapproved by Google Search Console because sitemaps included `/en/videos/` while canonical pointed to `/videos/`.
- *Redirect all `/en/*` paths to clean `/*` paths*: Eliminates duplicate routes completely at the static routing layer (`src/pages/[...slug].astro`).

## 2. Multilingual `hreflang` Implementation

### Decision
Enhance `src/components/Global/Meta.astro` to dynamically output `rel="alternate" hreflang` tags for `en`, `es`, and `x-default` for all page types.

### Implementation Details
For any given page (e.g., `videos`):
- `hreflang="en"` -> `https://glendaferreira.com/videos/`
- `hreflang="es"` -> `https://glendaferreira.com/es/videos/`
- `hreflang="x-default"` -> `https://glendaferreira.com/videos/`

For root homepage:
- `hreflang="en"` -> `https://glendaferreira.com/`
- `hreflang="es"` -> `https://glendaferreira.com/es/`
- `hreflang="x-default"` -> `https://glendaferreira.com/`

### Rationale
Explicit `hreflang` tags instruct Googlebot that `/videos/` and `/es/videos/` are localized equivalents, preventing Google from treating them as duplicate content or unindexed alternate pages.

## 3. Sitemap & Configuration Alignment

### Decision
Update `astro.config.mjs` integration for `@astrojs/sitemap`:
- Configure `site: "https://glendaferreira.com"`.
- Remove restrictive filter `pathname.startsWith("/en/") || pathname.startsWith("/es/")` which excluded root `/` and clean paths like `/videos/`.
- Filter out 404 pages and internal doc pages in production.

### Rationale
Ensures `dist/sitemap-0.xml` includes all canonical URLs (`https://glendaferreira.com/`, `https://glendaferreira.com/es/`, `https://glendaferreira.com/videos/`, `https://glendaferreira.com/es/videos/`, etc.) and eliminates non-canonical entries.
